## Quick Reference

| Question | Answer |
|----------|--------|
| **Where to configure agents?** | Next.js Dashboard → Agent Config Studio |
| **Where is agent logic?** | LangChain service (Python) |
| **Where are workflows?** | n8n (each agent has its own workflows) |
| **Where is client data?** | PostgreSQL (with row-level security) |
| **Where is knowledge base?** | Pinecone (per-tenant namespace) |
| **Where are integrations?** | n8n nodes connect to external services |
| **How does AI work?** | LangChain calls OpenAI/Claude via RAG pipeline |
